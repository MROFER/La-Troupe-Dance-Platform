# La-Troupe-Dance-Platform

Plataforma de formación en danza: cursos on demand, avance curricular, evaluación y certificados, profesores invitados con reparto de ingresos y, a futuro, SaaS para otras academias. LA TROUPE es la primera academia que la usa.

**Estado:** etapa de definición. Todavía no hay código de producto.
